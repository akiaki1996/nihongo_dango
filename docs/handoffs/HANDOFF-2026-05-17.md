## 代码变更

### 1. 新增 `src/scripts/convert-n3.ts`
从 n3.csv 到 seed 格式的转换脚本。使用时需确保 Node >= 18 且 better-sqlite3 已编译。

### 2. API 路由修复 — 添加 `runtime = 'nodejs'`
3 个 API 路由文件新增 `export const runtime = 'nodejs'`：

- `src/app/api/session/route.ts`
- `src/app/api/stats/route.ts`
- `src/app/api/answer/route.ts`

**原因**: better-sqlite3 是 C 扩展，必须在 Node.js Runtime 运行。不加此声明时，Next.js 14 可能在 Edge Runtime 下执行 API route，导致 `ERR_DLOPEN_FAILED`。

### 3. 数据库重建
旧 `data/app.sqlite` 已删除，重新 seed 生成含 2139 词的新数据库。
